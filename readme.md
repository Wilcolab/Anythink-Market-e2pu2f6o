# GitHub Copilot Demo

This is a demo project to show how GitHub Copilot can assist in writing API endpoints.

## Features

- GET all comments
- DELETE a comment by ID
- Async/await syntax
- Auto-generated documentation
- GitHub Copilot-assisted commit messages

## Setup

1. Install dependencies: `npm install`
2. Start the server: `npm start` or `npm run dev`
3. Use endpoints:
   - GET `/api/comments` — fetch all comments
   - DELETE `/api/comments/:id` — delete a comment
